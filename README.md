# Base Command widget - review pack

A single-file, self-contained copy of the Base Command page (the builder "link board"
dashboard from 100xbuilder.io), published here so outside developers can read and review
the widget code in isolation - no need to clone the whole platform.

## What's here

- `base-command.html` - the complete page: standard chrome (header, toolbar, bug reporter),
  the link-board widget, and its inline styles/scripts. Open it in a browser to see it run.

## How to review

Open `base-command.html` locally, or read it top to bottom. Comments in the file mark the
standard chrome block and the widget block. Notes, questions, and suggestions are welcome as
issues or pull requests.
